# Стойка хаоса и громила

## Игровая стойка

`forbidden_brews:chaos_brewing_stand` — блок и предмет. Рецепт на верстаке:

```text
А С А
  Н
О И О
```

А — осколок аметиста, С — обычная варочная стойка, Н — **слиток незерита**,
О — обсидиан, И — стержень ифрита. Результат — одна стойка.

Временная основа варки использует ванильные рецепты и интерфейс Brewing Stand.
Три слота для зелий, ингредиент, топливо, сигнал компаратора и воронки наследуют
обычную механику. Собственный зарегистрированный BlockEntityType сохраняет
идентификатор и инвентарь стойки. После подключения эффектов здесь появятся
рецепты Forbidden Brews.

Твёрдость — 4, сопротивление взрывам — 1200, свет — 7. Добыча требует алмазной
кирки или лучше; предмет стойки устойчив к огню. Размер модели — 16×24×16
единиц, то есть 1×1,5×1 блока. Верх модели выступает над блоком.

JSON-модель содержит 70 кубов. Атлас 256×256 использует примерно одну
текстурную точку на единицу модели. Игровой PNG содержит 24 вертикальных
кадра; `.mcmeta` задаёт 2 тика на кадр. Анимация меняет блики, жидкость и руны.
Вращение сердечника, кольца и плавание флаконов есть в художественных файлах
и превью; отдельного игрового BlockEntityRenderer пока нет. Флаконы на модели
декоративные и пока не отражают содержимое инвентаря.

## Громила

`art/blockbench/steve_brute.bbmodel` — редактируемый Generic Model с 35 кубами,
7 группами-костями и встроенной оригинальной текстурой 256×256. Его можно
открывать без платных плагинов. Группы: `root`, `body`, `head`, `left_arm`,
`right_arm`, `left_leg`, `right_leg`. Для Minecraft Java подготовлен
`art/java/BruteModelLayer.java` с теми же кубами и UV. Он компилируется во
всех трёх сборках, но пока не зарегистрирован в рендерере сущности.

Примерный габарит в покое: 38×46×16 единиц (2,375×2,875×1 блока).
Хитбокс сущности и правила прохода через двери ещё не определены.

Клипы в Blockbench:

| Клип | Длина | Движение |
|---|---|---|
| `idle` | 2 с, цикл | Дыхание и небольшое движение рук |
| `walk` | 1 с, цикл | Чередование шагов и раскачивание рук |
| `smash` | 1,8 с | Поднятие обоих кулаков, удар и восстановление |

Blender хранит отдельные действия для костей и текущую сцену с ударом.
GLB — текстурированная модель с иерархией узлов и анимацией, показанной в
превью. Файлы `.bbmodel` сохраняют полный набор авторских клипов.
Превью имеют 48 кадров и длятся 4 секунды. Это рендеры Blender, а не запись
готового превращения в Minecraft.

Для игровой формы ещё нужны регистрация сущности/рендерера, синхронизация
превращения Стива, длительность эффекта, камера и проверка разрушения 4×4.
Пока этой логики нет. Модель не заменяет обычный скин игрока.

## Сборка и воспроизведение

Forge 1.20.1 использует JDK 17; NeoForge и Fabric 1.21.1 — JDK 21.
Для Fabric нужен Fabric API 0.116.17+1.21.1. Сборки раздельные:

```sh
./gradlew -Ptarget=forge-1.20.1 build
./gradlew -Ptarget=neoforge-1.21.1 build
./gradlew -Ptarget=fabric-1.21.1 build
```

В PowerShell аргумент с версией следует заключать в кавычки:
`./gradlew.bat '-Ptarget=forge-1.20.1' build`.
Готовый JAR находится в `platforms/<target>/build/libs/`.
Установить его нужно на клиент и сервер с соответствующим загрузчиком.
В мире с командами: `/give @s forbidden_brews:chaos_brewing_stand`.

Исходные модели и текстуры создаются без внешних сетевых сервисов:

```sh
python tools/build_chaos_models.py
python tools/stage_runtime_resources.py
blender -b -t 8 --python tools/render_chaos_models.py -- --target chaos_brewing_stand --render animation
blender -b -t 8 --python tools/render_chaos_models.py -- --target steve_brute --render animation
python tools/build_model_previews.py
```

Нужны Pillow и Blender 5.2; превью используют системный шрифт Segoe UI.
Текстуры и кубы сделаны специально для проекта. Старые 3D-флаконы не входят
в публикуемые файлы.

## Проверки моделей и версии 0.1.0

Все три варианта `build` прошли. На Forge в настоящем GameTest-сервере
прошли три теста: рецепт и отказ при отсутствии/замене незерита; сохранение
инвентаря с собственным ID и рабочее меню; 402 тика зарегистрированного
обработчика, превращающие три воды в неловкие зелья с расходом топлива и
ингредиента. Запуск:

```sh
python tools/build_test_structure.py
./gradlew -Ptarget=forge-1.20.1 -PgameTests runGameTestServer
```

Тестовые классы и структура включаются только с `-PgameTests` и отсутствуют
в обычных выпускаемых JAR. Визуальную проверку игровых клиентов и серверные
GameTest для NeoForge/Fabric пока не запускали. Рендеры проверены отдельно
в Blender, включая полный замах громилы без обрезания модели.

Использованные первичные технические источники: [регистрация Forge](https://docs.minecraftforge.net/en/1.20.x/concepts/registries/),
[блоки NeoForge 1.21.1](https://docs.neoforged.net/docs/1.21.1/blocks/),
[группы предметов Fabric](https://wiki.fabricmc.net/tutorial:itemgroup),
[GameTest Forge](https://docs.minecraftforge.net/en/1.20.x/misc/gametest/),
[код формата Blockbench](https://github.com/JannisX11/blockbench/blob/master/js/formats/bbmodel.js).

Зельеварение 0.2.0 заменяет ванильное меню собственным и добавляет новую культуру. Актуальная инструкция и проверки: [brewing.md](brewing.md).
