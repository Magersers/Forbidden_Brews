# Forbidden Brews

Двумерные анимированные иконки зелий для Minecraft. Обычный стеклянный флакон, сияющая жидкость, движущиеся потоки, пузырьки и небольшие украшения по эффекту. **14 зелий × 2 версии = 28 иконок.**

## Файлы

- `art/icons/drink/` и `art/icons/splash/` — отдельные PNG 32×32 с прозрачным фоном.
- `art/minecraft/assets/forbidden_brews/textures/item/` — анимированные PNG 32×768: 24 кадра 32×32 вертикально, рядом `.png.mcmeta`.
- `previews/individual/` — отдельная GIF для каждого зелья и каждой версии.
- `art/catalog.json` — названия, цвета и задуманные эффекты.
- `tools/build_pixel_potions.py` — воспроизводимая сборка иконок и GIF.

| Зелье | Задуманный эффект |
|---|---|
| Переворот | Переворачивает экран |
| Дикий прыжок | Телепортирует в случайную точку карты |
| Домой | Возвращает домой |
| Призыв орды | Повышает спавн мобов даже днём |
| Крылья ночи | Превращает в летучую мышь |
| Разрушитель | Превращает в монстра, ломающего блоки 4×4 |
| Двойная руда | Умножает руду ×2 |
| Рудный охотник | Подсвечивает ближайшую руду |
| Перемирие | Мобы мирны, пока их не ударить |
| Сердце крипера | Взрыв с небольшим уроном; взрывная версия — как TNT |
| Горячая кирка | Мгновенная переплавка добываемой руды |
| Удача | Повышает удачу в зависимости от уровня |
| Трофеи охотника | Повышает добычу с мобов |
| Перевёртыш | Превращает в случайного моба |

Логика эффектов и регистрация предметов пока не реализованы. Этот этап содержит только 2D-графику; 3D-заготовки отклонены и не включены в репозиторий. Стойка хаоса в текущую 2D-серию не входит.

## Пересборка

Нужны Python и Pillow. Укажи локальный клиентский JAR Minecraft:

```sh
python tools/build_pixel_potions.py --vanilla-jar /path/to/minecraft-client.jar
```

GIF и `.mcmeta` воспроизводят 24 кадра по 100 мс: бесконечный цикл 2,4 секунды. Текстуры уже окрашены; дополнительное стандартное тонирование зелий при будущем подключении не требуется. Мягкое освещение от предмета в мире не реализовано: сияние нарисовано внутри самой текстуры.

Контур стекла и пробка используют стандартные текстуры `potion` и `splash_potion` из установленного Minecraft Java 1.21.1 (Mojang/Microsoft). Жидкость, анимация и украшения созданы для Forbidden Brews. Изображения в превью увеличены без размытия. Для создания подписей скрипт использует системный шрифт Consolas на Windows.
