# Forbidden Brews 0.4.2

Исправлена длительность отрицательного зелья «Переворот»: **I — 11 секунд, II — 22 секунды, III — 45 секунд**. Чем выше уровень, тем дольше эффект. Новые длительности применяются к питьевым и взрывным версиям, включая уже существующие флаконы; при взрыве время уменьшается с расстоянием по обычным правилам Minecraft. Молоко снимает эффект. Всего доступны 28 предметов и 28 рецептов.

| Файл | Minecraft / загрузчик | Java |
|---|---|---|
| [Forge](forbidden-brews-forge-1.20.1-0.4.2.jar) | 1.20.1 / Forge 47.4.0+ | 17 |
| [NeoForge](forbidden-brews-neoforge-1.21.1-0.4.2.jar) | 1.21.1 / NeoForge 21.1.252+ | 21 |
| [Fabric](forbidden-brews-fabric-1.21.1-0.4.2.jar) | 1.21.1 / Fabric Loader 0.16.14+, Fabric API 0.116.17+1.21.1 | 21 |

Замените предыдущий JAR в `mods/` на клиенте и сервере. [Рецепты](../../docs/brewing.md), [SHA-256](manifest.json). [GIF поворота и снятия молоком](../../previews/inversion_0.4.1_in_game.gif) записан в версии 0.4.1.

Три сборки успешно собраны и запущены на выделенных серверах. На Forge прошли 19 GameTest, включая проверку отрицательной категории, длительности 11/22/45 секунд, всех уровней и взрывных версий, снятия молоком и всех 28 рецептов. Клиентская запись и проверка матрицы поворота относятся к 0.4.1; повторная визуальная проверка в 0.4.2 не выполнялась.
