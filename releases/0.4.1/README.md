# Forbidden Brews 0.4.1

«Переворот» — отрицательное зелье трёх уровней: **I — 45 секунд, II — 22 секунды, III — 11 секунд**. Доступны питьевые и взрывные флаконы каждого уровня. Улучшения II/III появляются при установке предыдущего питьевого уровня в центральную ячейку стойки; рецепты требуют незеритовый нарост и более редкие компоненты. Время в интерфейсе отображается в минутах и секундах. Молоко снимает эффект.

Всего работают восемь составов: **28 предметов и 28 рецептов**. Остальные эффекты этой версии сохраняют прежнюю длительность.

| Файл | Minecraft / загрузчик | Java |
|---|---|---|
| [Forge](forbidden-brews-forge-1.20.1-0.4.1.jar) | 1.20.1 / Forge 47.4.0+ | 17 |
| [NeoForge](forbidden-brews-neoforge-1.21.1-0.4.1.jar) | 1.21.1 / NeoForge 21.1.252+ | 21 |
| [Fabric](forbidden-brews-fabric-1.21.1-0.4.1.jar) | 1.21.1 / Fabric Loader 0.16.14+, Fabric API 0.116.17+1.21.1 | 21 |

Установите подходящий JAR в `mods/` на клиенте и сервере, заменив предыдущую версию. [Рецепты](../../docs/brewing.md), [GIF Переворота](../../previews/inversion_0.4.1_in_game.gif), [GIF варки](../../previews/chaos_stand_ui.gif). SHA-256 — в [manifest.json](manifest.json).

Три сборки компилируются и запускаются на выделенных серверах. На Forge прошли 19 серверных GameTest, включая все уровни Переворота и 28 рецептов, а также проверка реальной матрицы поворота и запись клиента. NeoForge и Fabric проверены сборкой и запуском сервера; их клиентские эффекты отдельно не проверялись.
