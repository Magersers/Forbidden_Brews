# Forbidden Brews 0.1.0 — стойка хаоса

Установите один JAR для вашего загрузчика и версии Minecraft в папку `mods`.
На сервере и клиенте должна стоять одинаковая сборка мода.

| Сборка | Minecraft | Зависимости |
|---|---|---|
| `forbidden-brews-forge-1.20.1-0.1.0.jar` | 1.20.1 | Forge 47.4.0+, Java 17 |
| `forbidden-brews-neoforge-1.21.1-0.1.0.jar` | 1.21.1 | NeoForge 21.1.252+, Java 21 |
| `forbidden-brews-fabric-1.21.1-0.1.0.jar` | 1.21.1 | Fabric Loader 0.16.14+, Fabric API 0.116.17+1.21.1, Java 21 |

Добавлена стойка хаоса с крафтом через **слиток незерита**. Её можно поставить,
открыть и использовать для обычной варки трёх зелий. Работают топливо,
сохранение инвентаря и воронки. Предмет находится в функциональных блоках
творческого режима или выдаётся командой
`/give @s forbidden_brews:chaos_brewing_stand`.

Оригинальная модель громилы, её текстура и Java-слой подготовлены для
последующего превращения Стива. Самого моба и превращения в этой сборке
пока нет. Новые эффекты зелий также ещё не реализованы.

Все три JAR собраны; три игровых серверных теста Forge прошли. Проверка
изображения в игровом клиенте ещё не выполнялась. GIF в [основном README](../../README.md)
показывают художественные анимации Blender.

Контрольные суммы SHA-256 и размеры находятся в `manifest.json`.
