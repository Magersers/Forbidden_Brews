# Forbidden Brews 0.2.1

Обновлённая Удача = Fortune с бонусом к зачарованию инструмента; длительность I/II/III — 2/5/8 минут. Стрелки заменены выбором через ячейку, рецепты улучшений и взрывных версий фильтруются по центральному зелью.

Игровая партия: Удача I–III, Добыча I–III и Домой, питьевые и взрывные версии; собственная стойка с подсказками рецептов и анимацией; выращиваемый незеритовый нарост.

| Файл | Minecraft / загрузчик | Java |
|---|---|---|
| [Forge](forbidden-brews-forge-1.20.1-0.2.1.jar) | 1.20.1 / Forge 47.4.0+ | 17 |
| [NeoForge](forbidden-brews-neoforge-1.21.1-0.2.1.jar) | 1.21.1 / NeoForge 21.1.252+ | 21 |
| [Fabric](forbidden-brews-fabric-1.21.1-0.2.1.jar) | 1.21.1 / Fabric Loader 0.16.14+, Fabric API 0.116.17+1.21.1 | 21 |

Установите ровно один подходящий JAR в `mods/` на клиенте и сервере. [Рецепты и инструкция](../../docs/brewing.md), [GIF интерфейса](../../previews/chaos_stand_ui.gif). SHA-256 и размеры — в [manifest.json](manifest.json).

Три сборки прошли компиляцию и запуск выделенного сервера; 11 серверных GameTest и визуальный запуск выполнены на Forge. Прочие эффекты и превращение в громилу остаются следующим этапом.
