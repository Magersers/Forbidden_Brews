# Forbidden Brews 0.6.0

Добавлены **«Рудный охотник»** и **«Охотник»**, питьевые и взрывные версии на **2 минуты**, анимированные флаконы и рецепты с незеритовым наростом. Всего работают **12 составов, 36 предметов и 36 рецептов**. Меню показывает все 12 базовых рецептов без прокрутки.

Рудный охотник отмечает ближайшую руду в 16 блоках голубым контуром через стены; после добычи выбирает следующую. Охотник показывает враждебных мобов в 32 блоках и кнопки, нажимные плиты, нити и крюки растяжек в 24 блоках. Контуры видит только игрок с эффектом. Поиск не загружает новые чанки и распределён по тикам. Молоко снимает оба эффекта.

| Файл | Minecraft / загрузчик | Java |
|---|---|---|
| [Forge](forbidden-brews-forge-1.20.1-0.6.0.jar) | 1.20.1 / Forge 47.4.0+ | 17 |
| [NeoForge](forbidden-brews-neoforge-1.21.1-0.6.0.jar) | 1.21.1 / NeoForge 21.1.252+ | 21 |
| [Fabric](forbidden-brews-fabric-1.21.1-0.6.0.jar) | 1.21.1 / Fabric Loader 0.16.14+, Fabric API 0.116.17+1.21.1 | 21 |

Замените предыдущий JAR в `mods/` на клиенте и сервере. [Все рецепты](../../docs/brewing.md), [GIF подсветки](../../previews/potions_0.6.0_in_game.gif), [GIF варки](../../previews/chaos_stand_ui.gif), [SHA-256](manifest.json).

Три сборки успешно собраны; серверы трёх загрузчиков запускаются. На Forge прошли **25 GameTest**, включая все 36 рецептов и прежние эффекты. Запись настоящего клиента проверяет выбор рецепта, подсветку через стену, переключение после добычи, радиусы, исключение пассивных мобов, отсутствие глобального свечения и снятие молоком. Для NeoForge и Fabric выполнены сборка и серверный запуск; отдельная клиентская запись и GameTest не выполнялись. Летучая мышь, Разрушение, Перевёртыш и Гравитация ждут реализации.
