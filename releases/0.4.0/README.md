# Forbidden Brews 0.4.0

Добавлены **Переворот** и **Сердце крипера**, питьевые и взрывные версии, рецепты с незеритовым наростом и анимированные флаконы. Всего работают восемь составов: **24 предмета и 24 рецепта**. В меню доступны восемь базовых зелий без стрелок.

Переворот на 2 минуты разворачивает мир и предмет в руке на 180°; молоко снимает эффект, меню и HUD остаются читаемыми. Питьевое Сердце крипера взрывается с силой 3 и наносит выпившему 4 единицы базового урона с учётом сложности и защиты. Взрывное детонирует один раз в точке попадания с силой TNT 4.
