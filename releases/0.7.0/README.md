# Forbidden Brews 0.7.0

Рудный охотник показывает ближайшую руду сквозь стены с её **настоящей текстурой**, включая глубинные варианты, в радиусе 16 блоков. Добавлены оставшиеся **Крылья ночи, Разрушитель, Перевёртыш и Гравитация**: по 2 минуты, с питьевыми и взрывными версиями и собственными рецептами с незеритовым наростом. Теперь работают **16 составов, 44 предмета и 44 рецепта**; все 16 базовых рецептов доступны в меню без прокрутки.

Крылья ночи дают модель мыши и полёт с обычным управлением: двойное нажатие прыжка включает полёт, прыжок поднимает, приседание опускает. Разрушитель использует модель громилы, меняет размеры и добывает 4×4 с проверкой защиты блоков и расходом прочности инструмента. Перевёртыш выбирает одну из 15 сохраняемых форм мобов. Гравитация по первому отдельному нажатию прыжка поднимает к небу, по второму опускает на землю; удерживание не повторяет переключение. Молоко снимает эффекты и возвращает обычное движение.

Три сборки успешно собраны и запускают выделенный сервер. На Forge прошли **30 GameTest**, включая все 44 рецепта, прежние эффекты, новые превращения, полёт, сохранение формы, переключение гравитации, снятие молоком и добычу 4×4 с защитой блоков. Запись настоящего клиента проверяет выбор рецепта, текстуры руды, взлёт мыши, модель громилы, 16 выпавших блоков, случайную форму, оба направления гравитации, приземление и сброс движения. Для NeoForge и Fabric выполнены сборка и серверный запуск; отдельная клиентская запись и GameTest не выполнялись.
